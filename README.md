# MAXMA — прототип главной страницы

HTML/CSS/JS-прототип для показа дизайна клиенту. Свёрстан по макету
[Главная](https://www.figma.com/design/J5O8dq0z1hB7ba68lMvQYn/Untitled?node-id=14-128)
(`14:128`, 1440 × 8208), фиксированная ширина **1440 px**.

Блока «Максимум результата» пока нет — он будет перерисован. Всё, что в
макете ниже него, поднято на его место. Плюс от строки «Компании с MAXMA…» и ниже всё опущено на 60 px, чтобы под монитором было больше воздуха: `y на странице = y в Figma + 60` до «Одной платформы» включительно и `y в Figma − 772` ниже.

## Запуск

Открыть `index.html` в браузере. Сборка не нужна.

Для локального сервера (чтобы шрифты и ассеты гарантированно
подхватились в любом браузере):

```
npx http-server -p 8080 .
```

## Публикация на GitHub Pages

Включается один раз владельцем репозитория:
**Settings → Pages → Build and deployment → Source: `Deploy from a branch`**,
ветка `claude/maxma-website-prototype-lywv3c`, папка `/ (root)` → *Save*.

После этого каждый пуш в эту ветку пересобирает страницу автоматически,
адрес будет `https://serezhaok.github.io/Maxma/`.

Все пути в разметке относительные, поэтому проект корректно работает из
подпапки `/Maxma/`. Файл `.nojekyll` в корне нужен, чтобы Pages отдавали
файлы как есть и не прогоняли их через Jekyll.

## Структура

```
index.html            разметка
css/styles.css        стили: токены, координаты блоков, компоненты
js/main.js            табы, карусель кейсов, формы, скролл-анимации
assets/fonts/         Object Sans (woff2 + woff)
assets/img/           экспорты из Figma — см. ASSETS.md
ASSETS.md             что и откуда экспортировать
```

## Как устроена вёрстка

Все блоки верхнего уровня лежат внутри `.stage` (1440 px по ширине) и
спозиционированы абсолютно по координатам из Figma — так проще всего
держать пиксель-в-пиксель на фиксированной ширине. Внутри блоков
используется обычный flex, повторяющий auto-layout макета.

У каждого блока проставлен `data-node` с его Figma node ID — можно
сверять с макетом напрямую.

Цвета, отступы, кегли, межбуквенные и тени взяты из Figma без округления
(`57.283px`, `-2.2913px`, `79.812px` и т. д.).

## Интерактив

- шапка зафиксирована на весь скролл; «Тарифы» и «Блог» пока не
  кликабельны;
- «Продукт» открывает мегаменю (макет `29:1191`): по наведению или клику,
  страница под ним притемняется; закрывается, когда курсор уходит с пилюли
  и панели, по Esc или клику по затемнению;
- первый экран: по мере скролла градиентная подложка раскрывается
  на всю ширину, а монитор со стикерами подрастает на 15% — анимация
  проходит за первые 700 px скролла;
- на экране монитора — зациклённое видео дашборда (`autoplay muted loop`);
- якорные ссылки — плавный скролл к секциям;
- табы «Одежда и аксессуары / Здоровье / …» (пока только тост);
- «Одна платформа»: переключение сегмента подвозит нужную карточку по
  горизонтали; три карточки (`platform-1` … `platform-3`) повторяются
  по шести табам;
- две строки с результатами клиентов проявляются из прозрачности при скролле;
- карусель кейсов — стрелки под блоком, шаг равен ширине карточки + 16 px;
  карточки не обрезаются по фрейму и уходят в белые поля на широких
  экранах; горизонтальный скролл при этом гасится на `html`;
- в результатах клиентов выделенные цифры подчёркиваются по наведению;
- обе формы валидируются на клиенте и показывают тост.
  **Никуда ничего не отправляется** — это прототип.

## Ассеты

Все картинки выгружены из макета и лежат в `assets/img/` — список и
node ID в [ASSETS.md](ASSETS.md).

## Известные ограничения

- Только 1440 px. Адаптива нет — это макет-презентация, не продакшен.
  На окне уже 1440 px страница целиком уменьшается до ширины окна
  (`zoom`), на более широком стоит по центру в масштабе 1:1.
- Rubik подключён с Google Fonts — нужен интернет. Без него текст в футере
  откатится на Object Sans.
- Карточки-коллажи (кейсы, модули платформы, Uptime, поддержка, визуал
  у формы) — цельные экспорты с текстом внутри. Правки текста в них
  делаются в Figma и перевыгрузкой картинки.
