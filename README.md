# MAXMA — прототип главной страницы

HTML/CSS/JS-прототип для показа дизайна клиенту. Свёрстан по макету
[Main page concept](https://www.figma.com/design/rvnkwI3A1eiLfX71NL843O/Maxma--website--MASTER-?node-id=2916-16729)
(`2916:16729`), фиксированная ширина **1440 px**, высота страницы —
ровно 10088 px, как во фрейме.

## Запуск

Открыть `index.html` в браузере. Сборка не нужна.

Для локального сервера (чтобы шрифты и ассеты гарантированно
подхватились в любом браузере):

```
npx http-server -p 8080 .
```

## Структура

```
index.html            разметка
css/styles.css        стили: токены, координаты блоков, компоненты
js/main.js            табы, карусель кейсов, формы, лента логотипов
assets/fonts/         Object Sans (woff2 + woff)
assets/img/           экспорты из Figma — см. ASSETS.md
ASSETS.md             что и откуда экспортировать
```

## Как устроена вёрстка

Все блоки верхнего уровня лежат внутри `.stage` (1440 × 10088) и
спозиционированы абсолютно по координатам из Figma — так проще всего
держать пиксель-в-пиксель на фиксированной ширине. Внутри блоков
используется обычный flex, повторяющий auto-layout макета.

У каждого блока проставлен `data-node` с его Figma node ID — можно
сверять с макетом напрямую.

Цвета, отступы, кегли, межбуквенные и тени взяты из Figma без округления
(`57.283px`, `-2.2913px`, `79.812px` и т. д.).

## Интерактив

- шапка и якорные ссылки — плавный скролл к секциям;
- табы «Все сферы / Фэшн-ритейл / …» и вертикальные табы этапов платформы;
- карусель кейсов — стрелки под блоком, шаг равен ширине карточки + 16 px;
- лента логотипов — бесконечная прокрутка, останавливается по наведению,
  выключается при `prefers-reduced-motion`;
- обе формы валидируются на клиенте и показывают тост.
  **Никуда ничего не отправляется** — это прототип.

## Ассеты

Картинки и логотипы из макета в репозиторий не попали: в среде, где
собирался прототип, закрыт исходящий доступ к `www.figma.com`. Слоты под
них размечены с точной геометрией и показывают нейтральную заглушку.

Чтобы всё встало на место — экспортируйте файлы по списку в
[ASSETS.md](ASSETS.md) и положите в `assets/img/` под теми же именами.
Правок в коде не потребуется.

## Известные ограничения

- Только 1440 px. Адаптива нет — это макет-презентация, не продакшен.
- Rubik подключён с Google Fonts (нужен интернет); офлайн-фолбэк —
  Object Sans. Подробности в ASSETS.md.
- Часть мелкой декоративной графики собрана кодом, а не экспортом —
  список в ASSETS.md.
