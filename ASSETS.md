# Ассеты для экспорта из Figma

Файл: `Maxma (website) MASTER` → `rvnkwI3A1eiLfX71NL843O`
Фрейм: **Main page concept** → `3026:659` (1440 × 8418)

Скачать ассеты автоматически не получилось: в этой среде исходящий доступ
к `www.figma.com` закрыт egress-политикой (прокси отдаёт 403 на CONNECT),
поэтому экспортов в репозитории нет.

Вёрстка от этого не ломается. Каждый ассет — это слот с точной геометрией
по макету; пока файла нет, слот показывает нейтральную заглушку вместо
битой картинки (`js/main.js` → `hydrateAssets`). Как только файл появится
в `assets/img/` под указанным ниже именем, он подставится сам —
ничего править в коде не нужно.

## Как экспортировать

В Figma выделить узел по ID (`Ctrl/Cmd + /` → *Copy link* или поиск по
node-id), затем **Export**.

**Расширение можно не угадывать.** Слот в разметке называет ассет, а не
файл (`data-asset="hero-dashboard"`), и загрузчик сам перебирает
`.svg → .png → .webp → .jpg → .jpeg → .webm → .mp4` и берёт то, что
реально лежит в `assets/img/`. Поэтому логотип, сохранённый как `.svg`
там, где в таблице написано `.png`, всё равно подхватится.

**Видео поддерживается.** Если положить `.webm` или `.mp4`, слот
превратится в зациклённое видео (`autoplay muted loop playsinline`)
вместо картинки. Так сейчас работает дашборд на первом экране —
`hero-dashboard.webm`. Видео вписывается в бокс целиком, без обрезки.

Колонка «Формат» ниже — это рекомендация (что лучше смотрится), а не
требование.

## Что собрано кодом вместо экспорта

Иконки берутся из **Google Material Symbols Outlined**, начертание
`wght 300`, `FILL 0`, `GRAD 0` — ровно как подписано в макете
(`bolt_24dp_..._wght300_GRAD0_opsz24` и т. п.). Шрифт подключается с
Google Fonts, экспортировать иконки не нужно:

| Иконка | Node ID | Имя в Material Symbols |
|---|---|---|
| Молния, первый экран | `2929:17133` | `bolt` |
| Токен, первый экран | `2929:17137` | `token` |
| Кружок активного таба платформы | `2916:16892` | `photo_auto_merge` |
| Щит, 152-ФЗ | `2916:16774` | `security` |
| Градиент, «Прозрачный старт» | `2916:16912` | `gradient` |
| Стрелки у цифр и в списке «Maxma делится инсайтами» | `2976:17454`, `3036:1540` | `arrow_outward` |
| Стрелки карусели кейсов | `2968:17417`, `2968:17419` | `chevron_left` / `chevron_right` |

Если иконочный шрифт почему-то не загрузился, иконки просто не
показываются — вместо них не появится текст «bolt».

Остальная декоративная графика собрана средствами CSS/SVG. Выглядит
близко к макету, но если нужна стопроцентная копия — экспортируйте и
замените:

|---|---|---|

| Свечения в тёмной карточке кейса | `2968:17435`, `17436`, `17437` | Размытые радиальные градиенты `.blob` |
| Аватар в мини-карточке 2FA | `2916:16757` | Сплошной круг `#7851e0` |

## Плейсхолдеры, ждущие ваших деталей

- **Карточки «Одна платформа»** сейчас берутся из трёх макетов
  `platform-1` … `platform-3`, разложенных по шести сегментам по кругу
  (1, 2, 3, 1, 2, 3). Когда будут остальные три — положите
  `platform-4` … `platform-6`, и разметка подхватит их без правок.
- `platform-01-screen.png` от прежней сборки больше не используется —
  можно удалить.
- **Иконки шагов 2–5** в блоке «Максимум результата»: в макете нарисован
  только первый шаг (`gradient`). Сейчас стоят `rocket_launch`,
  `support_agent`, `bolt`, `trending_up` — пришлите нужные имена из
  Material Symbols, поменяю.
- **Иконка кружка у табов платформы** одна на все сегменты
  (`photo_auto_merge` из макета) — если у каждого своя, пришлите список.

## Шрифты

**Object Sans** (в Figma подписан как *PP Object Sans*) уже лежит в
`assets/fonts/` — Light / Regular / Medium / Bold / Black, woff2 + woff,
подключён через `@font-face`. Ничего доустанавливать не нужно.

Два места в макете используют другие гарнитуры:

- **Rubik Medium** — списки ссылок и юридический текст в футере.
  Подключён с Google Fonts. Если презентация пойдёт **офлайн**, положите
  woff2 рядом с Object Sans и добавьте `@font-face`, иначе там
  подставится Object Sans.
- **TT Norms Tochka Extended** — подпись в мини-карточке 2FA
  (`2916:16761`, `2916:16762`). Заменено на Object Sans.

Ещё в файле встречаются стили `Point Soft: Bold` и `Unnamed: Bold`
(телефон/почта и заголовок подписки в футере) — судя по всему, это
неразрешённые ссылки на шрифты внутри Figma, а не отдельная гарнитура.
Свёрстано Object Sans Bold; если это ошибка макета — скажите, поправлю.
